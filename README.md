# Millbrook Swifts website

A responsive static website for Millbrook Swifts Football Club, designed to be hosted free with GitHub Pages.

## Files
- `index.html` — website content and sections
- `style.css` — layout, colours and responsive styling
- `script.js` — mobile navigation and current year
- `assets/millbrook-swifts-kit.png` — club kit showcase image

## Publish with GitHub Pages
1. Sign in to GitHub and create a **New repository**. For example, name it `millbrook-swifts`.
2. Choose **Public** (or use a plan that supports Pages for private repositories).
3. Upload the contents of this folder to the repository's root. Make sure `index.html` is in the root, not inside another folder.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then click **Save**.
7. Wait a minute or two. GitHub will show your website address, usually `https://YOUR-USERNAME.github.io/millbrook-swifts/`.

## Before publishing
- Add the club's real contact email address to the Contact section in `index.html`.
- Add confirmed team names, age groups, fixture dates, results and social links when available. The current fixture area is deliberately marked as coming soon rather than showing invented information.
- Replace the kit image in `assets/` if you have a higher-resolution official image.

The site is plain HTML, CSS and JavaScript. No build tools or paid hosting are required.
